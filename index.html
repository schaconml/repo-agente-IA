            Protocolos de Rescate Git Inmediato
          

          
¿Qué acaba de ocurrir en tu proyecto universitario?

          

            Git rara vez destruye información a menos que ejecutes comandos forzados destructivos. Selecciona tu caso de estrés y sigue los pasos con calma.
          

        


        
        


          
          

            

              Emergencia Común
              #RAMA-ERRONEA
            

            
Hice commit en main/master en vez de mi rama de equipo

            
Crea la rama correcta desde tu punto actual y luego rebobina main sin tocar tus archivos.

            

              
$ git checkout -b feature/mi-rama-correcta

              
$ git checkout main

              
$ git reset --soft HEAD~1

            

            
          


          
          

            

              Sincronización
              #PUSH-REJECTED
            

            
Mi push fue rechazado porque un compañero subió cambios

            
Nunca hagas force push. Aplica un rebase para montar tus commits limpios sobre los suyos.

            

              
$ git pull --rebase origin main

              
$ git push origin feature/entrega

            

            
          


          
          

            

              100% Seguro
              #RESET-SOFT
            

            
Hice commit con error y quiero arreglarlo sin perder código

            
El parámetro --soft elimina el registro del commit pero mantiene todos tus cambios listos en staging.

            

              
$ git reset --soft HEAD~1

              
$ git status

            

            
          


          
          

            

              Bolsillo Temporal
              #GIT-STASH
            

            
Tengo código a medias y necesito cambiar de rama ya

            
Guarda tus modificaciones en una gaveta temporal para dejar tu área de trabajo limpia.

            

              
$ git stash save "wip: cambios parciales"

              
$ git checkout otra-rama

              
$ git stash pop
